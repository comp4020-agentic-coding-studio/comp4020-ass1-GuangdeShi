# Reflection — Assignment 1

## What was the breakthrough that moved the work forward?

The breakthrough was realising that "interactive" does not simply mean "input changes output". The
BaZi prototype technically worked, but the user's action did not explain the system. Life Cost
became stronger when every interaction and representation was judged by whether the visitor
learned through the action itself.

## What did this work change about who I want to be as a software developer?

The second insight is about agentic development: the developer's role is not simply to ask the
agent for more output. It is to define boundaries, reject plausible but off-brief choices, encode
corrections into the harness, and verify both successes and reported failures before accepting
them.
